Two-panel income vs. expenditure chart, built from your WorldAces transaction ledger. Everything below runs in your browser — nothing you paste is uploaded anywhere.

Get your data

The WorldAces API doesn't allow direct browser requests (no CORS headers), so this page can't fetch your transactions for you with just a token — the request gets blocked by your browser before it even reaches api.worldaces.site.

Instead, run the CLI version once (it isn't subject to CORS) to fetch and page through your ledger automatically, then either look at the PNG it writes directly or paste its JSON below:

python ledger_bars.py --token YOUR_BEARER_TOKEN --outjson transactions.json --out ledger.png

Get the script from the tool folder (also copyable as a single standalone file), install matplotlib, then swap in your own bearer token. --outjson writes the raw transactions so you can paste them below too. Add --theme dark if you'd rather match this page.
